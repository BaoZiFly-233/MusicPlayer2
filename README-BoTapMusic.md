# BoTapMusic

基于 [MusicPlayer2](https://github.com/zhongyang219/MusicPlayer2) 的 Windows 桌面音乐播放器，在本地播放、歌词、频谱和均衡器之外，提供K源与B源的在线浏览和播放。

## 在线音乐

在默认界面 1、2 中选择「在线音乐」导航，或点击工具栏的地球图标；Groove Music 界面使用左侧在线音乐入口。菜单「工具 → 在线音乐搜索」也可切换到同一页面。页面使用播放器原生皮肤组件，沿用背景、主题、字体和播放控制条。

- **发现与搜索**：查看热搜，双击热搜发起搜索；输入歌名或歌手后按 Enter，双击歌曲播放。搜索会先列出歌曲，后面跟上同名专辑，双击专辑即可列出那张专辑的曲目。列表列宽随窗口自适应：宽屏分「标题 / 艺术家 / 专辑 / 状态 / 时长」，窄屏把艺术家与专辑并为一列；状态列给出「试听」或「无损」，来源是各平台的权限与音质字段（B源看 listen_fragment 与 audios，K源看 AlbumPrivilege 与 SQ），不需要点开才知道能不能听。
- **推荐与榜单**：K源榜单、B源排行榜及分类可直接浏览；B源提供匿名推荐，K源个人推荐需要登录。
- **云歌单**：查看K源账号歌单、B源精选歌单及登录后的喜欢/创建/收藏歌单。更多菜单支持按关键词搜索B源歌单、打开歌单编号和完整导入本地。
- **本地歌单**：保存在线或本地歌曲，自动跳过重复项。播放与加入队列使用播放器现有播放引擎，可继续浏览其他页面。
- **操作进度**：搜索、登录、歌单加载与换源、播放准备、下载和缓存等共用底部进度区域，沿用皮肤配色和字体；媒体库窗口采用 Windows 标准进度条。显示当前阶段、实际数量或下载字节、耗时和结果，未知总量时显示等待动画。多任务可展开查看或切换，支持取消的任务提供取消入口，结束提示可关闭。切换在线页面不会中断歌单导入与换源。
- **自动换源**：在线歌曲无法播放时，默认到另一音源查找同一首歌，确认可靠匹配和播放地址后继续播放，并恢复原位置。仅替换本次播放的音源，原歌单不变；过程显示在底部进度区域，可取消。在在线页「更多操作 → 无法播放时自动换源」中可关闭。没有可用匹配时，按原有播放错误设置停止或跳过。
- **导入与导出**：工具栏文件夹图标可导入本地歌单，也可粘贴外部平台歌单分享链接后自动匹配到当前音源，并保存为独立的原生 `.playlist`，支持用「语种/歌单名」形式保存到子目录，可在「媒体库 → 播放列表」中按分组重命名、编辑和删除；在线“本地歌单”页的旧数据可通过右键菜单或更多菜单「保存为原生播放列表…」迁移，也可用操作栏的「清空」按钮一键清理；保存图标导出选中歌曲，未选择时导出当前已加载的歌曲。支持 M3U8、BoTapMusic JSON、原生 `.playlist`，导入还兼容 M3U、WPL、TTPL。
- **账号与歌词**：按所选音源扫码登录，账号页显示用户名与会员状态；在线歌词和封面自动获取并缓存。普通 LRC 整句高亮，带逐词时间的歌词才逐词填色，滚动歌词和桌面歌词均适用。
- **下载与缓存**：播放页工具栏的“下载”按钮保存当前在线歌曲，更多菜单可批量保存。下载将歌曲信息、歌词和封面内嵌到音频文件；平台未提供的内容会显示缺失状态。默认预缓存下一首，上限 1 GiB；可查看状态、开关或清理缓存。同名文件自动编号，缓存清理不删除手动下载。缓存查找以无损优先；只存在有损缓存时会再解析一次，能取到更高音质就改播网络流并由后台缓存，取不到仍回退到缓存，离线也能播。
- **签到与看广告领会员**：K源账号页的更多菜单可领取当天会员、检查到账或开启自动签到；自动签到默认关闭，仅在播放器运行期间检查。K源还有广告奖励：一次上报换 3 小时会员，每天最多 8 次，领满相当于全天畅听；它和每日奖励在同一次自动流程里完成，进度与累计时长显示在账号页。B源支持官方的看广告领会员：激励视频一次换 30 分钟大会员畅听，账号页的更多菜单可立即领取或开关自动观看。B源另有赚金币体系：听歌分九级（5 秒到 3 小时，36 到 188 金币），签到分七级（288 到 8888 金币），每天自动领取一次，余额显示在账号页。金币不等于无损：实测兑换「无损音质天卡」后，账号态取流依然只到 320k，真正的无损由匿名链路提供，所以金币默认只领不花。自动观看默认开启，播放器运行期间在权益到期前自动补领，播放撞上付费墙时也会先领一次再重试同一首；每日次数与发放结果以平台为准，没领到会说明具体原因。音质也是走这条链路：解析播放地址时优先用匿名新版接口，权益生效后付费曲直接取无损，而带账号的同类请求反而会被判成 20018。

列表支持 Ctrl / Shift 多选、Ctrl+A 全选和右键操作；有内容时上下键、PageUp / PageDown、Home / End 在列表里移动，Enter 打开或播放，Ctrl+G 定位到正在播放的那一行，F5 刷新，本地歌单页 Delete 移除，详情页 Esc 返回。鼠标指到歌曲行会出现「播放 / 下一首播放 / 加入队列 / 收藏」四个小按钮，已收藏的行显示实心红心；停在一行上会有完整信息的提示，播放失败过的行（灰色）在提示里写出原因，再双击就是重试。状态栏右侧显示正在播放的音质（无损 / 320k / 本地缓存），操作结果几秒后回落为列表摘要。底部箭头用于返回、定位、刷新、加载更多。窄窗口使用页面下拉框节省空间；窗口高度不足时，请拉高窗口并收起右侧播放列表。其他皮肤可通过 `<onlineMusic/>` 元素接入。

右键菜单与工具栏的「更多操作」是同一份定义，按用途分组并补齐了原生播放器里本该有的操作：播放所选、下一首播放、加入播放队列、加入播放列表…、加入「我喜欢」、保存到在线本地歌单、从本地歌单移除、保存为原生播放列表…、换源到…、下载所选到文件夹、导出所选、打开文件所在位置、查看歌词、复制歌曲信息。「更多操作」另外带整页操作：导入歌单、把当前播放列表换源到…、打开歌单编号、完整导入云歌单、下载与缓存、账号与签到。菜单项按行类型区分：点在专辑、歌单或榜单行上只给「打开」。媒体库里右键一份歌单也有「换源到…」，作用对象就是那份歌单（导入进来的歌单主要从这儿换源）。

本地文件、K源、B源三者严格分开：来源只看歌曲地址本身（本地路径／`kugou://`／`bodian://`），每一行左侧有来源图标（本地音符、在线地球），宽屏的状态列写成「K源 · 无损」这样，列表里混着多个来源时标题还会带上 `[K源]` 前缀。「浏览音源」下拉框只影响浏览和搜索，不改变已保存的歌单和正在播放的曲目，播放地址永远按地址里的 scheme 解析。

「换源到…」会按标题、歌手和时长匹配另一平台。播放列表与媒体库歌曲列表中的单曲、所选歌曲会写回原歌单，并留下同名 `.bak` 备份；期间切换歌单仍只更新原目标。当前播放的歌曲换源后重新开流并恢复位置和播放状态。对整份歌单换源或对尚未归属歌单的搜索结果换源时，结果另存为新歌单。本地文件、同源歌曲与未可靠匹配的曲目均保留，保存失败会显示原因。

切歌不卡在解析上。平台播放地址有时效，但在几分钟内重复解析同一首没有意义，因此线上地址会短时记在内存里：后台预缓存解析成功后写进备忘，用户真正切到这一首时直接命中，不再在播放路径上等一轮网络往返；播放失败、登录、退出、签到和领取会员都会让相关备忘失效。歌词与封面各有独立后台线程，互不阻塞。读接口（搜索、榜单、歌词、封面地址）遇到网络抖动会自动重发一次，签到和领会员这类改服务端状态的请求不重试。

BoTapMusic JSON 歌单可完整保存虚拟地址、歌曲信息和 CUE 时间信息。导出前写入临时文件，成功后替换目标；读取无效 JSON 时拒绝整份导入。云歌单只有完整读取成功后才写入本地。

## 构建与运行

需要 Visual Studio C++ 生成工具（MSVC v143、MFC）及 Windows SDK。

本机（BoTapMusic 开发机）的生成工具装在 `D:\VSBuildTools`，没有注册到 `vswhere`，直接调用即可：

```bat
call "D:\VSBuildTools\VC\Auxiliary\Build\vcvarsall.bat" x86
"D:\VSBuildTools\MSBuild\Current\Bin\MSBuild.exe" MusicPlayer2.sln /p:Configuration=Release /p:Platform=x86
```

其他机器换掉这两条路径。链接前先关掉正在运行的播放器：程序是单实例的，运行中的 `MusicPlayer2.exe` 会让链接报 `LNK1104`；`--test-online` 系列自检在单实例检查之前处理，播放器开着也能跑。

编译产物为 `Release/MusicPlayer2.exe`，运行目录需要 BASS 相关库、`Plugins`、`Encoder`、`SciLexer.dll`、`tag.dll`。将 `MusicPlayer2/skins` 复制到运行目录的 `skins`，并复制 `MusicPlayer2/default_background.jpg`。已验证构建目标为 Release x86。

构建中间产物用 `bash scripts/clean-build.sh` 清理（只删未纳入版本库的 obj/pdb/tlog 等，保留运行目录和符号文件）。

## 验证

```powershell
MusicPlayer2.exe --test-online            # 歌单、异步页面与自动换源回归
MusicPlayer2.exe --test-online --network  # 增加公共音源、自动换源与静默解码检查
MusicPlayer2.exe --test-online --playback # 解析临时歌单第一首K源歌曲并静默解码
MusicPlayer2.exe --test-online --media-cache # 在临时目录验证完整下载、歌词、缓存命中及保存
MusicPlayer2.exe --render-online-preview # 使用合成歌曲导出原生皮肤预览
MusicPlayer2.exe --test-source           # 搜索与播放地址解析诊断
```

在线检查及预览命令以退出码 0 表示通过，非 0 表示失败。日志写入配置目录的 `online_test.log`、`online_playback_test.log`、`online_media_test.log`；皮肤预览在 `ui-preview`。导出预览不代替实际窗口交互验证；静默解码不验证扬声器输出。扫码确认、个人云歌单与会员播放需要对应账号验证，在线自检不会提交签到领取，也不会提交广告上报。

## 音源与歌单说明

在线歌曲保存为 `kugou://...` 或 `bodian://...` 虚拟地址，播放时优先使用完整缓存，否则解析有时效的音频地址。普通播放器不一定识别这些虚拟地址；导出歌单不包含音频文件。需要音频文件时使用「保存所选歌曲到文件夹」。

歌曲是否可完整播放由平台、曲目和账号权限决定。K源登录状态保存在配置目录的 `kugou.ini`，失效后需重新扫码；不要分享这个文件。B源登录凭据在本机加密保存；扫码未返回凭据时，可从更多菜单选择自己的 `uid` / `token` JSON 文件导入。音质按 `flac → 320 → 128` 尝试。

下一首预缓存保存在配置目录的 `online_cache`，单曲上限 256 MiB。当前歌曲播放不会触发音频缓存下载；后台提前下载实际队列中的下一首，支持顺序、列表循环、随机和无序播放。队列变化会取消旧预缓存，关闭开关不影响手动下载。歌词缓存独立于音频缓存开关。

## 代码导航

| 文件 | 职责 |
|---|---|
| `OnlineSource.*`、`OnlineJson.h` | 音源抽象、浏览数据和字段适配 |
| `OnlineHttp.h` | HTTPS 请求、超时和响应大小限制 |
| `KugouSource.*`、`KugouCrypto.*` | K源接口、签名、账号和设备身份 |
| `BodianSource.*` | B源浏览、歌单、账号、播放权限和歌词 |
| `OnlineMediaCache.*` | 下一首预缓存、歌词后台任务、手动下载及容量清理 |
| `OnlineDailyRewards.*` | K源当天会员记录与领取、B源看广告领会员的自动续期 |
| `OnlineMusicModel.*` | 页面状态、后台请求、歌单与账号操作 |
| `OnlineProgress.*` | 在线操作进度、阶段、取消及结束状态 |
| `UIElement/OnlineMusic.*` | 原生皮肤导航、搜索、列表和详情 |
| `Playlist.*` | 播放列表格式及安全写入 |

结构、固定版本参考和采用边界见 [在线音乐开发说明](docs/ONLINE_MUSIC.md)。早期音源实现与兼容性记录见 [工程记录](docs/HANDOVER.md)。接口参考 KuGouMusicApi、PyBodian 和 lmplayer，保留平台权限校验。

源文件要求 UTF-8 BOM，资源文件保持原有 UTF-16 编码。修改后执行：

```powershell
pwsh -File scripts/check-bom.ps1
```

脚本默认检查有改动的文件；`-Fix` 用于为已确认采用 UTF-8 的文件补 BOM。不要批量转换上游未修改的文件。
