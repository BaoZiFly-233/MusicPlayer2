# 在线音乐开发说明

## 原生界面

在线页面是 `UiElement::OnlineMusic` 复合元素，由现有 `NavigationBar`、`SearchBox`、`ComboBox`、`Button` 和 `AbstractListElement` 构成。背景、配色、字体、透明度及播放控制来自当前皮肤。在线浏览不创建独立页面窗口。

默认界面 1、2 与 Groove Music 的正常及窄布局在已有 `stackElement` 中增加在线页。原有播放、歌词、队列及媒体库页面仍是相邻页。小高度布局主要用于播放控制，需要扩大窗口后使用在线浏览。

皮肤作者可以在内容区的 `stackElement` 中增加 `<onlineMusic margin="8"/>`，并通过 `navigationItem` 指向该页。`<button key="onlineMusic"/>` 切换在线区域，关闭时恢复先前的内容页。Groove 导航预设 `item_list` 中的 `online_music` 对应在线入口。页面宽度小于 500 个逻辑像素时，七个页签改用下拉框。

## 状态与并发

`COnlineMusicModel` 在窗口线程处理命令、文件选择、账号保存和播放队列交接；绘制线程只读取不可变 `State` 快照。原生列表将选中行和列表版本一起投递，替换结果后旧选择不能操作新行。追加分页保持原行选择。

浏览操作在一个后台工作线程中顺序执行，等待执行的请求只保留最新一个。每个请求持有独立音源快照；切换页面或关闭播放器后丢弃过期结果。隐藏页面时停止扫码轮询、取消当前浏览操作；未完成的普通浏览在返回后从第一页重载。完整歌单导入和歌词预览不会自动转换成其他操作重试。音频缓存、自动歌词及每日会员领取使用独立任务，浏览页面隐藏不会中断已排队的保存。

HTTP 请求统一由 `OnlineHttp.h` 管理，要求 HTTPS，连接和接收有超时，响应限制为 8 MB。先收集响应字节再解码 UTF-8，避免多字节字符在网络分块处被截断。请求错误以页面状态显示，不将账号或播放地址写入测试日志。

## 浏览接口

| 页面 | 酷狗概念版 | 波点音乐 |
|---|---|---|
| 发现 | `/api/v3/search/hot_tab` | `/api/search/hot/list` |
| 搜索 | 现有签名搜索接口 | `/api/search/music/list` |
| 推荐 | `/everyday_song_recommend`，需要登录 | `/api/service/resource/recommend` |
| 榜单 | `/ocean/v6/rank/list` | `/api/service/home/module?moduleId=5` 的排行榜及 `/api/service/category/list` 的分类 |
| 榜单歌曲 | POST `/openapi/kmr/v2/rank/audio` | `/api/service/bang/{id}/musics`、`/api/service/category/{id}/musics` |
| 云歌单 | POST `/v7/get_all_list`，需要登录 | 匿名：首页模块 2 的精选歌单；登录后：`playlist/fond`、`playlist/userCreate`、`collect/4/list` |
| 公开歌单搜索 | 通过编号打开歌单 | `/api/search/playlist/list` |
| 歌单歌曲 | `/pubsongs/v2/get_other_list_file_nofilt` | `/api/service/playlist/{id}/musicList?source=…` |

酷狗请求保留接口要求的 router、签名和 GET / POST 区别。`/v5/url` 同时携带 key 与完整参数的 Android 签名；播放地址兼容根对象的 `url` / `backupUrl` 数组及旧版 `data` 包装。服务错误保留状态码，权限不足时尝试较低音质，签名错误不重复请求其他音质。榜单歌曲解析 `data.songlist`、`audio_info.hash_128` 和 `duration_128`。波点分类内容解析 `data.musicList`。整数与字符串形式的歌曲编号均在适配层归一化，无效编号不生成虚拟地址。接口可能变化，调整字段前应核对响应及相应上游实现。

波点歌单标识携带来源，内部表示为 `编号_来源`；已适配 4、5、13，不能仅保留歌单编号。排行榜使用 `bang_编号` 与分类区分。排行榜和歌单曲目页码从 1 开始；搜索及分类延续对应接口的页码约定。

## 音频缓存、歌词与封面

`COnlineMediaCache` 在配置目录的 `online_cache` 保存完整音频和 UTF-8 BOM 歌词，以虚拟地址的 MD5 作为文件名。只将地址用于当前下载任务，不将地址、令牌或接口响应写入缓存索引。播放优先命中完整缓存，缺失时只解析正常播放地址，不再为当前歌曲启动音频缓存下载。

下一首预缓存默认开启，设置键为 `cache.prefetch_next`，旧的 `cache.enabled` 不再控制当前歌曲缓存。播放状态锁内根据实际队列确定下一首，后台音源快照解析并下载；重复检查同一目标不重复排队。显式“下一首播放”优先，随机播放预留候选，无序播放提前生成下一轮排列，并在实际切歌时使用该候选或排列。预留过程不推进当前曲目或播放历史。单曲循环且没有其他待播歌曲时不预缓存当前曲目。

目标变化、停止播放或关闭预缓存会取消旧目标，预缓存取消代数独立于手动下载和歌词任务。容量为 1 GiB，单曲限制为 256 MiB，完成后按文件时间清理较早缓存。HTTP 音频 CDN 与 HTTPS 均支持，账号接口仍要求 HTTPS。文件头决定 MP3、FLAC、OGG、M4A 或 WAV 扩展名；拒绝不支持的格式、HTTP 错误、超限和已知长度不符的响应。临时文件完整关闭后才原子移入缓存，启动时清理残留下载片段。预缓存减少下一首的网络等待，不改变播放内核的切歌流程。

播放页工具栏的下载按钮在点击时保存当前歌曲快照，再选择文件夹；按钮显示下载状态，更多菜单也可批量保存所选歌曲。手动保存复用完整缓存，缺失时由账号快照解析播放地址。先复制到目标目录临时文件，通过现有 TagLib 写入歌曲信息、内嵌歌词及封面，全部可用标签写入成功后再改名；同名文件自动递增编号，失败不会替换已有文件。下载仅生成音频文件。平台缺少歌词或封面时保留音频并显示缺失项，播放缓存不受标签写入影响。缓存清理会取消尚未完成的下载，并只删除本服务管理的缓存文件，不删除已保存到其他目录的歌曲。状态页显示排队数及本次下载成功、失败数。

封面优先采用曲目返回的图片地址，缺失时按标题和歌手搜索并核对同一曲目标识。图片下载限制为 8 MiB，校验格式和原生解码后存入缓存；窗口线程核对当前曲目再刷新封面及媒体控制信息。封面和歌词共用独立资源队列，不阻塞播放解析。

歌词逐词填色以每句实际解析出的逐词时间为条件。普通 LRC 使用整句高亮；混合歌词按句判断。保留原始行进度供滚动、长句位置和双行切换使用，不生成推算的逐词时间；桌面歌词使用同一判断。

自动歌词使用独立线程。酷狗先向 `https://lyrics.kugou.com/v1/search` 发送带 Android 签名和对应客户端请求头的查询，再通过候选 `id/accesskey` 下载 LRC；波点解码 `/api/service/music/lyric/{id}` 返回的 Base64。歌词经原生 `CLyrics` 解析后落盘，窗口线程仅向当前匹配歌曲回填，滚动歌词和桌面歌词使用同一份数据。旧的本地歌曲下载任务也在回填时核对歌曲身份，避免快速切歌后覆盖新歌。

## 账号与每日会员

账号页异步获取用户名、会员类型和有效期。酷狗使用用户详情及联合会员接口，优先显示概念版会员状态；波点使用用户信息接口。未返回的字段显示“未获取”，不推断为非会员。显示资料仅保存在运行内存，退出账号时清除。

波点扫码采用 `/api/ucenter/login/qrCode`、`qrCodeStatus` 和 `/api/ucenter/users/login`。带时间戳的新版接口使用查询签名；GET 携带 JSON 的播放接口保留 GET 方法，不能按请求体是否为空推断方法。账号播放先检查 `music/v2/checkRight`，仅完整权限状态 1、4 才请求 `music/v2/audioUrl`，不把试听片段当成完整歌曲。音质按 FLAC、320 kbps、128 kbps 尝试。

波点账号可通过用户选择的 JSON 文件导入 `uid`、`token`，验证成功后才接入当前账号。持久化使用当前 Windows 用户的 DPAPI，退出账号删除本机凭据。扫码获取与等待状态可独立验证；手机确认后能否返回完整凭据、个人歌单及会员音质仍需要对应账号验证。

`COnlineDailyRewards` 提供酷狗当天会员领取及自动签到开关，默认关闭。开启后仅在播放器运行期间检查；先读取 `/youth/v1/activity/get_month_vip_record`，以服务端的北京时间日期检查当天领取记录。未领取时向 `/youth/v1/recharge/receive_vip_listen_song` 发送空请求体 POST，参数为当天 `receive_day` 和正常活动 `source_id=90139`。提交前先持久化账号哈希和尝试日期，同一账号一天只提交一次。提交后重新读记录，只有记录确认才显示到账；不明结果不会重复提交。不会补领过去日期，也不自动完成听歌或广告任务。波点尚未接入有可靠证据的日常签到接口。

## 歌单与播放

本地在线收藏存储在配置目录的 `online_library.playlist`。重复判断复用原生歌单逻辑。导入文件上限 16 MB；云歌单全量导入逐页读取，最多 500 页，任何页失败都不保存部分结果。

导出支持 `.m3u8`、`.playlist`、`.btplaylist` / `.json`。JSON 格式为：

```json
{"format":"BoTapMusic","version":1,"songs":[{"path":"bodian://42","title":"示例歌曲","artist":"示例歌手","album":"示例专辑","is_cue":false,"start_ms":0,"end_ms":180000,"track":0,"cue_path":""}]}
```

JSON 导入校验版本及每个条目，失败时不接收部分歌曲。M3U8 保留 `EXTINF`，并用扩展标签保存精确标题、歌手和专辑；其他播放器可能忽略扩展标签。所有格式先写同目录临时文件，再原子替换目标，写入失败保留原文件。

播放动作通过 `CPlayer::OpenOnlineSongs` 进入原有播放流程。直接播放使用临时播放列表；加入队列保留当前歌曲、位置和播放状态，文件夹模式下生成可保存的队列。加载中返回忙状态，保存失败不替换队列身份。

## 回归范围

`--test-online` 覆盖三种格式的元数据往返、重复读取、目标锁定时保留文件、M3U 注释及相对路径、无效 JSON、版本拒绝、去重、接口字段类型，以及列表版本、异步取消和分页结果应用；还覆盖波点凭据加密、歌单来源、日常领取记录、缓存片段拒绝、同名保存、取消结果不落盘和清理边界。

`--test-online --network` 增加两个平台的公共热搜、搜索、榜单与歌曲下钻、波点推荐/精选歌单/歌单搜索、波点二维码获取与等待状态，以及封面查询、已有酷狗账号的用户名、概念版会员状态和会员记录只读检查。该模式不会提交会员领取。歌词可用性单独记录，因为部分曲目没有歌词。

`--test-online --media-cache` 读取临时播放列表中第一首酷狗歌曲，在独立临时目录验证播放解析不触发缓存、下一首预缓存完整下载、歌词解析、播放命中本地缓存、BASS 静默解码、原生封面回填、歌词与封面内嵌读回、保存后音频数据及总时长不变和清理后保留手动文件；完成后清理测试目录。离线检查还覆盖随机候选稳定性、无序下一轮衔接、过期预缓存取消不影响手动下载，以及普通和逐词混合歌词。`--test-online --playback` 直接对网络播放流作静默解码检查。这两种方式验证解码数据，不验证扬声器输出。

`--render-online-preview` 调用实际 `CUserUi` 绘制器，将合成歌曲渲染为默认界面与 Groove Music 的明暗、宽窄布局 PNG。该模式不播放歌曲、不保存用户设置；它验证绘制输出，不证明实际窗口中的鼠标、键盘或音频行为。
